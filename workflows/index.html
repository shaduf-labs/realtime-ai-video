Workflow notes: conditions first

These are source-backed starting points, not install endorsements. Confirm the current license, model files, hardware, and version compatibility before a production use.

Comfy’s official H3 access route: a footprint is not a speed claim

Comfy says: its optimized H3 path prunes modulation weights, uses INT8 ConvRot, and reduces the smallest variants’ total memory footprint from 123.6 GB to 42.5 GB. It says dynamic VRAM offloading can run H3 on a GPU like an RTX 3060.

That is useful for a first local test. It does not say which task mode, resolution, duration, quality, system RAM, retry rate, or wall time fits that card.

Even a 5090 needs a full condition card

Community report: one r/comfyui author reports a roughly 15-second 768×1024 H3 result in about 22 minutes on an RTX 5090 and 64 GB RAM, using 362 frames at 24 fps, eight steps, a Turbo sampler, and a stated LoRA. That is an offline result; it is neither a general 5090 benchmark nor a cost-free route.

Community issue: a current development-version report describes higher VRAM pressure and interrupted H3 work on a 32 GB RTX 5090 D with 128 GB RAM. One issue does not prove a regression, but it makes software revision and launch flags part of the hardware answer.

New ComfyUI H3 features are test leads

Framework release notes say: ComfyUI v0.35.0 adds H3 features including PDD LoRA support and H3 Max options. Community report: one issue says the experimental core Block Sparse Attention node failed in an H3 workflow on that version.

A feature being shipped is not a repeatable speed or reliability promise. Keep the exact ComfyUI version, hardware, workflow, node mode, and error log beside any improvement claim.

FastH3 Preview: local paths opened, narrow modes

Project says: FastVideo documents local FastH3 Preview on Apple Silicon MLX and on one or two NVIDIA DGX Sparks. Its cookbook limits the MLX route to T2VA—text-to-video with audio—after a local DiT conversion. FL2VA and Ref2VA are not wired there.

The source’s fastest local preview result still takes 119 seconds for a 124-frame clip, so start with a short offline test rather than a streaming plan. Keep full H3 VAE separate from its TAEH3 preview decoder, because the project says the shortcut softens fine detail.

Community longform signal: 12 GB does not mean quick

Community report: one author says a 12 GB RTX and 64 GB DDR5 can produce a 60-second H3 result in 35 minutes 11 seconds with a Turbo path. This is a lead for an offline long-shot experiment, not a live claim, a general 12 GB recommendation, or a quality benchmark.

Record task mode, source material, resolution, frames, steps, model files, system RAM, GPU, version, seed, cold and warm wall time, and failures. A workflow without those fields is a screenshot, not a dependable route.

Related records: Comfy H3 note, ComfyUI v0.35.0 release, current 5090 D issue, FastVideo cookbook, the 5090 community report, and the 12 GB longform community report.
