Workflow directory · checked 12 September 2026

Workflow notes: conditions first

These are source-backed starting points, not install endorsements. Confirm the current license, model files, hardware, and version compatibility before a production use.

Comfy’s official H3 access route: a footprint is not a speed claim

Comfy says: its optimized H3 path prunes modulation weights, uses INT8 ConvRot, and reduces the smallest variants’ total memory footprint from 123.6 GB to 42.5 GB. It says dynamic VRAM offloading can run H3 on a GPU like an RTX 3060.

That is useful for a first local test. It does not say which task mode, resolution, duration, quality, system RAM, retry rate, or wall time fits that card. Keep “it started” separate from “it produced the shot I need before I gave up.”

FastH3 Preview: local paths opened, narrow modes

Project says: FastVideo documents local FastH3 Preview on Apple Silicon MLX and on one or two NVIDIA DGX Sparks. Its cookbook limits the MLX route to T2VA—text-to-video with audio—after a local DiT conversion. FL2VA and Ref2VA are not wired there.

The Apple path is not a lightweight laptop promise. The project’s published M4 Max runs use 36 GB unified memory. Its DGX Spark route is a CUDA 13, workstation-class path; two boxes use sequence parallelism over their QSFP link. The source’s fastest local preview result still takes 119 seconds for a 124-frame clip, so start with a short offline test rather than a streaming plan.

Quality condition: the project calls full H3 VAE the quality path and TAEH3 a fast preview decoder. It says the preview decoder softens fine detail. Keep the decoder name next to every timing result.

MiniMax H3 local base

Provider says: the MiniMax repository publishes separate FL2VA and Ref2VA checkpoint families. FL2VA covers text and first/last-frame inputs; Ref2VA covers multimodal reference inputs. The provider documents 4–15 second output at 24 fps, with 768p as the local base route.

The full 2K workflow is a different route: its documented flow combines a local H3 base with hosted Context-IR and Regenerate-2K components. Do not call a base-only local clip a full local 2K reproduction.

16 GB community record: a usable baseline card

Community report: a repository author reports MiniMax H3 T2V on Windows 10 with an RTX 5060 Ti 16 GB, 32 GB RAM, and PCIe 3.0 x8. The stated 1024×576, 5.2-second T2V times are 171.6 seconds with a Turbo option and 379.2 seconds without it. That is a condition-rich lead for an offline experiment, not a live claim or a general hardware recommendation.

Fresh community questions around 8 GB and 12 GB VRAM reinforce the same rule: memory labels alone hide task mode, system RAM, output duration, offload, and wait. A workflow record without those conditions is a screenshot, not a dependable route.

Related reports: Comfy H3 note, FastVideo MiniMax H3 cookbook, 16 GB H3 workflow record, and open H3 version-performance issue.
