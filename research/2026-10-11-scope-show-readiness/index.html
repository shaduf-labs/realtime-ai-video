Pool topic: Real-time, continuous, and interactive AI video generation. Question revision: 1. Exact question: What can generate continuous, interactive AI video today, and which setups work at which cost, latency, hardware requirements, and quality?

Checked 11 October 2026 · Existing route, not a new release

Scope has a browser stream. A paid live show needs more than FPS.

Scope's WebRTC example sends an input video track, receives generated video, and accepts prompt changes over a data channel. That is a documented live client path, unlike a model example that only saves an MP4. It does not establish a reliable paid-event service.

One operator's test

Community report: a prospective music-event operator in Thailand tested Scope 0.2.5 with remote beta inference on an H100. They reported 5m02s cold GPU provisioning plus 4m41s first LongLive load with two LoRAs, then 15–35s warm restarts. At 512×512, LongLive text-to-video plus RIFE held roughly 30 backend FPS, while a separate StreamDiffusionV2 video-to-video run reached 7.67 backend FPS and 6.26s media time to first frame. These are different tasks, not a speed ranking. No venue screen or glass-to-glass delay was measured. Read the operator's conditions.

Before a paid event

Project says: the repository's alpha code is licensed CC BY-NC-SA 4.0 for non-commercial use. Hosted-service terms and model or plugin rights need separate checks; do not assume the repository license clears a paid show. The same operator asked about one-hour session rollover, regional GPUs, data retention and post-beta pricing, without a project answer in the discussion at this check. They also observed a falling beta credit balance while connected but idle; that is not a settled billing rate. Check the repository and the open questions.

Useful next test: for the exact venue and pipeline, timestamp cold readiness, camera-to-screen change, a prompt switch, one failed connection and the one-hour handover. Record connected-idle and active charges. Get the paid-use position in writing before selling the result. This pool has not run Scope.

Sources checked 11 October 2026: Scope repository and license statement, WebRTC video-to-video guide, server and network notes, and one self-reported event-operator test. Performance, operating cost and licensing clearance are not pool-verified.
