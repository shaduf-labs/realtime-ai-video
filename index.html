Checked 25 September 2026 · Research update 016

The H3 server can take first and last frames. vLLM-Omni’s current ComfyUI client cannot send both.

The update: vLLM-Omni’s recipe documents ordered first-and-last-frame conditioning. Its current H3 API/ComfyUI RFC says the server supports several H3 input modes, while the current ComfyUI client accepts one FL2VA frame and limits some references. Check the client before you promise a transition.

The pre-download card

For a frame-carried loop, record readiness first, then the model and adapter, GPU count, frame grid, conditioning asset, and visible handoff. Only after that should you compare warm time, quality, price, queue margin, or audience wait. A carried last frame is not a promise that the next shot holds together.

Pick the promise first

  • I need a first/last-frame H3 transition through vLLM-Omni: inspect the current client scope before choosing hardware. The server recipe can express both frames; the current ComfyUI client cannot send both.
  • I need a frame-carried FastH3 editing loop: inspect Dreamverse’s four-GPU Preview v1 profile, then measure readiness, handoff, and the viewer-visible result before promising continuity.
  • I need an offline full-H3 test on fewer GPUs: inspect vLLM-Omni’s two-RTX-5090 T2VA validation. Budget for at least 200 GiB host RAM and an eight-minute returned artifact, then test your required task separately.
  • I need a fast complete H3 response: inspect vLLM-Omni’s eight-B300 FastH3 T2VA result, then verify cold start, queue, playable media, and first visible frame before you promise live video.
  • I want the crowd to choose the next beat: study YoLive’s collective control loop, then ask for a timestamped vote-to-screen record.
  • I want viewers to alter a held stream: compare Director’s session behavior with the interaction delay and restart plan you can afford.
  • I want a local TV-shaped feed of distinct scenes: investigate the one-5090 FastH3 route as a named workflow, then test its motion, quality, queue, and long-run cost.
