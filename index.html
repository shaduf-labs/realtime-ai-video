Checked 28 September 2026 · Research update 019

vLLM-Omni can return longer H3 clips. The full wait is still unknown.

Project says: vLLM-Omni v0.30.0 adds Ref2VA long-video continuation. A maintainer reports one 30.667-second original-H3 output on eight B300 GPUs, but not the full wall time or a live result.

What works today

The new long-video route returns a completed H3 clip, not a live session. The prior VAE timing still applies only to ComfyUI H3 workflows. Neither changes the live status of the routes below. Read the long-video boundary.

The pre-download card

For a frame-carried loop, record readiness first, then the model and adapter, GPU count, frame grid, conditioning asset, and visible handoff. Only after that should you compare warm time, quality, price, queue margin, or audience wait. A carried last frame is not a promise that the next shot holds together.

Choose the required behavior

  • I need a longer completed H3 clip: the v0.30.0 Ref2VA continuation route is a lead. Test the full wait, audio/video join, memory, and usable-output cost before treating the 300-second request guard as usable duration.
  • I need a first/last-frame H3 transition through vLLM-Omni: inspect the current client scope before choosing hardware. The server recipe can express both frames; the current ComfyUI client cannot send both.
  • I need a frame-carried FastH3 editing loop: inspect Dreamverse’s four-GPU Preview v1 profile, then measure readiness, handoff, and the viewer-visible result before promising continuity.
  • I need an offline H3 test on two RTX 5090s: the documented DLO launch selects FL2VA, which also serves T2VA. Budget for a 384 GiB host and an eight-minute returned artifact, then test your required task separately.
  • I need a fast complete H3 response: inspect vLLM-Omni’s eight-B300 FastH3 T2VA result, then verify cold start, queue, playable media, and first visible frame before you promise live video.
  • I want the crowd to choose the next scene: study YoLive’s collective control loop, then ask for a timestamped vote-to-screen record.
  • I want viewers to alter a held stream: compare Director’s session behavior with the interaction delay and restart plan you can afford.
  • I want a local continuous feed of distinct scenes: investigate the one-5090 FastH3 route as a named workflow, then test its motion, quality, queue, and long-run cost.
