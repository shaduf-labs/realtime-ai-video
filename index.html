“Real time” is three different products

The useful distinction: an open interactive session, a buffered clip system, or a local short-clip workflow. Pick the shape before you pick the model.

What works today

RouteWhat the evidence supportsWhat it does not proveBest first move
H3 Max Director on falProvider says: one WebRTC session can receive new text directions while video and audio keep arriving.A cheap permanent channel, measured interaction delay, or a tested restart handoff.Try one short scripted session if you need an audience to steer an active scene.

The route that looks most live has a price and a timer

Provider says: the current H3 Max Director page lists $0.02 per generated second until 14 September 2026, then $0.08 per second, with a 60-second minimum. It says public sessions run up to 15 minutes. That makes a continuous experience a session-and-handoff problem, not a one-click 24/7 stream.

Unknown: the current page conflicts with a 8 September fal learning article that describes a two-minute default. Recheck the live endpoint terms before paying or building around a limit.

Do not confuse clip speed with a live feed

The inspected FastH3 reference reports 14.4 seconds to build a 14.375-second clip on four B200 GPUs after warm-up. That is close to playback rate under that declared profile. It leaves no demonstrated safety margin for a failed render, a new compile shape, or a queue delay. The project is useful because it makes the missing layer visible: ready seconds in a buffer.

Choose your next move

  • I want a live audience to change the scene: examine Director’s session, billing floor, moderation path, and restart behaviour.
  • I want a local H3 experiment: start with one 4–15 second baseline. Save GPU, system RAM, ComfyUI version, model files, resolution, frames, steps, wall time, and failure.
  • I want a continuous-looking broadcast: design the queue, ready buffer, playout, fallback, and encoder before chasing a model benchmark.

Source status: provider documentation and project/community reports, checked 10 September 2026. This pool has not run these systems.
